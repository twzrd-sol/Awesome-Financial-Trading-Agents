# Contributing to Awesome AI Trading Agents

Thank you for your interest in contributing! This project aims to maintain the most comprehensive and up-to-date list of **AI Financial Trading Agents**, **AgentFi** platforms, and **Multi-Agent Systems** for finance.

## How to Contribute

1.  **Fork the repository.**
2.  **Add your project or platform** to the appropriate section in `README.md`.
    *   Ensure the link is valid and points to the official site or repository.
    *   Provide a concise (1-2 sentence) description.
    *   Include relevant **keywords** (e.g., `Keywords: Multi-Agent, LLM, Quant`).
3.  **Check for duplicates.** Please ensure the project isn't already listed.
4.  **Open a Pull Request (PR).**
    *   Use a clear title (e.g., `Add [Project Name] to Open-Source section`).
    *   Briefly explain why this project is a good fit for the "Agentic Finance" ecosystem.

## Criteria for Inclusion

*   **Agentic Capabilities:** The project should focus on autonomous or semi-autonomous agents (reasoning, planning, collaboration) rather than just simple signal bots or static algorithms.
*   **Active Maintenance:** For open-source projects, they should ideally have recent commits or a clear roadmap.
*   **Transparency:** Links should lead to verifiable documentation or code.

## Formatting Guidelines

Please follow the existing Markdown format:

```markdown
- **[Project Name](Link)**  
  *Keywords: Keyword 1, Keyword 2*  
  Description of the project and its agentic features.
```

Thank you for helping build the future of intelligent trading!
